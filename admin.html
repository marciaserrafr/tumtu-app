Instrumentos

Biblioteca mestre — vale para todas as escolas. Cada categoria pode ter mais de um nome possível (nomenclatura); cada bateria escolhe qual usar em "Configurações → Instrumentos" no painel dela.

Categoria de Figurino

Biblioteca mestre — vale para todas as escolas. Cada categoria (Camisa, Fantasia...) já nasce com sua própria escala de tamanhos (Medida); cada bateria escolhe quais categorias e tamanhos usar em "Configurações → Categoria de Figurino" no painel dela.

Figurino

Biblioteca mestre — vale para todas as escolas. Cada peça (ex: Camisa da Final) é ligada a uma Categoria de Figurino só pra usar o tamanho dela, e pode cobrir um ou mais públicos ao mesmo tempo. Cada bateria escolhe quais peças usa em "Configurações → Figurino" no painel dela — nasce tudo desligado.

Tipos de Evento

Biblioteca mestre — vale para todas as escolas. Ex: Ensaio, Ensaio Técnico, Apresentação, Reunião. Cada bateria escolhe o tipo ao criar um Evento próprio, em "Configurações → Eventos" no painel dela. Faz parte do módulo de Presença via QR.

Temporadas

Biblioteca mestre — vale para todas as escolas. Ex: Carnaval 2026, Carnaval 2027. Usada como rótulo opcional em Eventos, pra manter tudo padronizado (evita gente digitando "Carnaval 2026" de jeitos diferentes).

Privacidade
Exclusão de dados sob pedido (LGPD) — ações sem volta, com prova registrada abaixo.
Excluir dados de uma pessoa
Busca por nome, CPF ou e-mail — encontra até quem não tem vínculo com nenhuma bateria hoje.
Excluir uma escola inteira
Apaga a escola, as baterias e todos os vínculos ligados a elas. Fichas pessoais de quem ficar sem vínculo em nenhum lugar são preservadas.
Histórico de exclusões (prova)
Registro imutável — ninguém, nem Super Admin, consegue editar ou apagar um item daqui depois de criado.

Ritmistas
Enquanto ligado, o ritmista consegue preencher — nunca editar depois de salvo — qualquer campo de Medida que estiver em branco na própria ficha. Útil quando surge uma Categoria de Figurino nova no meio da temporada (ex: um vestido) e as pessoas precisam preencher esse campo sozinhas. Vale pra bateria inteira.
Campo sensível, tratado à parte de Instrumento/Medidas: os dois interruptores acima controlam só a própria ficha do ritmista (Meu Perfil), e são independentes. Pra Mestre/Diretor/Apoio verem ou marcarem o Repique de Bossa de um ritmista, a permissão é dada pessoa por pessoa, no grupo de cada cargo — ninguém tem acesso até ser liberado, mesmo quem já edita Ritmistas normalmente.
Só "ver" — o ritmista nunca marca nenhum dos dois, só enxerga o valor já definido pela Diretoria. Declaração só aparece de fato pra quem é menor de idade.
Só "ver" — o ritmista nunca edita, só a Diretoria escreve. Nasce desligado.
